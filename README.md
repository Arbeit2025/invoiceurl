# 請求書URL共有メーカー（invoiceurl）

請求書データをサーバーに保存せず、URL だけで共有するための小さな Web ツールです。

## 仕組み（大事なところ）

- 入力した請求書データは、ブラウザの中で JSON 化され、base64url 形式に変換されて、共有リンクの **フラグメント（`#` より後ろ）** に埋め込まれます。
- URL のフラグメントはブラウザからサーバーへ送信されないため、**請求書データがサーバーに保存されることは一切ありません**（データベースも持ちません）。
- リンクを受け取った人が `/view#…` を開くと、ブラウザがフラグメントを読み解いて請求書を表示します。印刷ボタンからそのまま印刷／PDF 化できます。
- つまり **リンク自体が請求書データそのもの** です。リンクを知っている人は内容を見られるので、送り先にはご注意ください。

## 使い方

1. 発行者名・住所、請求先名、請求日、支払期限、消費税率（10%／8%）を入力します。
2. 品目は1行に1つ、「品名,数量,単価」の形式で書きます（例：`デザイン料,1,50000`）。
3. 「共有リンクを作成」を押すとリンクが表示されるので、コピーして相手に渡します。
4. 相手が開いた請求書ページで、小計・消費税・合計が自動計算されます（消費税は切り捨て）。

金額の符号化／復号は、ページ内 JavaScript と `app.py` の `encode_payload` / `decode_payload` で同じ方式（UTF-8 JSON の base64url）になっており、テストで往復変換を確認しています。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- データは URL に埋め込むため、品目が多いとリンクが非常に長くなります。
- リンクを失くすと請求書も復元できません（サーバーに控えがありません）。
- 適格請求書（インボイス）の登録番号欄など、厳密な帳票要件には対応していません。簡易な請求書共有のための道具です。
- ログイン機能はありません。
